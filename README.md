# GUDORY (구도리)

> You don't need a photographer's sense. GUDORY turns the owner's **sense** of the shot they want into instructions the person holding the phone can follow with their ears, hands and feet.

## Problem
The person you hand your phone to is not short on skill — they are short on your sense. In the 30 seconds they give you, a translucent overlay does not tell them what to fix first.

## Solution
Compute the error on each axis and say **only the biggest one**, in words a body can act on ("one step back", "lower the phone by one fist"), on screen, with beeps that speed up as it gets closer and a vibration when it lines up. When it matches, the shot is taken automatically. The target comes from one of two modes.

## Features
1. **Sense coaching** — pose estimation + sensors compute four axes (level, distance, horizontal, height); one on-screen instruction at a time, with proximity beeps and haptics. Portrait and landscape shots.
2. **추천 모드 (recommend)** — CLIP reads the background, finds similar well-shot photos of one person, and proposes their composition. A 5-step bar chooses 인물 중심 ↔ 배경 중심.
3. **맞춤 모드 (custom)** — load one or more reference photos; the active one's composition becomes the target.

## Structure
```
app/     Flutter app (Android) — features/camera (Taeho) · coach (Eungyu) · scene = recommender (Seojun)
tools/   Python: one-person photos → recommend.json (background clusters + median compositions per framing)
data/    Downloaded photos (not committed)
api/     Vercel function: LLM proxy for multilingual instructions
docs/    Plan and concept documents
```
AI: ML Kit Pose / Selfie Segmentation (on device), CLIP ViT-B/32 ONNX (on device; a larger model is downloaded when online), Lablup DeepSeek (multilingual instruction text, via server). Photos never leave the phone.

## Run locally
```bash
# 1) Fetch model files (not in the repo)
python tools/fetch_models.py
# 2) App
cd app && flutter pub get && flutter run      # real Android device, Flutter 3.44.8
# 3) Data pipeline (optional)
cd tools && uv run build_assets.py --photos ../data/photos --out ../app/assets
```
